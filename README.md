# Mohammed Umair Jibran — Co-op ePortfolio

[Visit my ePortfolio](https://mjumair7.github.io/UmairJibran-ePortfolio/)

A separate version of my [personal portfolio](https://github.com/mjumair7/UmairJibransPortfolio), focused on my Computer Engineering program, co-op learning and technical projects.

## Pages and sections

- Introduction: my program, U+ learning reflection and career direction
- Projects: six case studies with contributions, tools, outcomes and visual examples
- Experience, lab work and community involvement
- Downloadable résumé
- About Me slideshow, PowerPoint slides and narration script
- Contact email

## Run locally

Serve this folder with `python3 -m http.server 4173` and visit `http://localhost:4173`.

Plain HTML, CSS and JavaScript; no build step. Motion respects the system reduced-motion setting. The project demos use sample data.

## About Me recording

The recorded About Me video is embedded in the portfolio and available at `assets/about-me.mp4`. The seven-slide presentation and narration script remain available as supplementary downloads.
