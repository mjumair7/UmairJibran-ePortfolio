01 / INTRODUCTION

Hi, I’m Umair.

My program: Bachelor of Engineering in Computer Engineering at York University, with graduation expected in 2028.

Why I chose engineering

I like being able to make something and then follow what happens inside it. With Computer Engineering, I can start at a circuit, write the firmware and see how software uses the result. That’s what I enjoy about the program: I get to build things and understand the details behind them.

My most rewarding co-op learning experience

The most rewarding part of U+ has been helping volunteer developers get a feature ready for people to use. Turning a request into a Jira task sounds small, but it makes me work out what’s actually needed. Reviewing code and testing releases has taught me to explain a problem clearly enough that someone else can fix it.

Where I want to go

I’m aiming for an embedded systems role where I can write firmware, bring up sensor interfaces and test how devices recover from communication failures. Longer term, I’d like to lead an embedded product team and still be involved in the design.

02 / EMBEDDED SYSTEMSHardware bench

CAN-FD test bench

Two STM32 boards, one CAN-FD link.

One board sends temperature and RPM data. The other checks each message before controlling a fan. I wanted to see what the actuator would do if those messages arrived late or stopped altogether.

My part
I wrote the FreeRTOS tasks, queues and timers, then made a Python harness that captures traffic and delays or drops frames.
Tools & methods
STM32, C/C++, FreeRTOS, CAN-FD and Python; message validation and fault injection.
Result
The bench checks message identity, integrity and freshness before using the data. My tests cover the transition to a safe output and recovery when valid messages return.
